LifeHub 개인정보처리방침

시행일: 2026년 10월 20일

1. 앱과 처리 목적

LifeHub는 개인용 일정·가계부·자산 관리 앱입니다. 사용자가 연결을 승인한 Google 서비스의 데이터는 사용자가 요청한 일정 동기화 및 금융 알림 전달에만 이용합니다.

2. 접근하는 Google 사용자 데이터

  • Google Calendar 일정: 사용자가 연동한 일정의 제목, 날짜, 시간 등 동기화에 필요한 정보
  • Google Drive 앱 전용 데이터 저장 영역: 모바일 보조 앱에서 전달한 금융 알림의 저장·수신에 필요한 파일
  • OAuth 인증 정보: Google API 접근에 필요한 사용자 승인 및 갱신 토큰

3. 데이터 이용 및 보관

LifeHub의 일정·거래 기록은 사용자의 로컬 장치에 저장될 수 있습니다. 동기화를 위한 일부 정보는 사용자가 승인한 Google Calendar 또는 Google Drive 앱 전용 영역에 저장됩니다. OAuth 인증 정보는 앱이 Google API에 접근하기 위해 사용자의 장치에 보관합니다.

4. 제3자 제공 및 사용 제한

LifeHub는 사용자 데이터를 광고나 판매를 목적으로 제공하지 않습니다. Google API를 통한 데이터 처리는 사용자가 승인한 동기화 기능 제공 범위 내에서 이루어집니다. Google API에서 받은 정보를 이용한 활동은 Google API Services User Data Policy를 준수하도록 운영합니다.

5. 사용자의 통제와 삭제

사용자는 앱의 Google 연동을 해제하거나 Google 계정의 제3자 앱 연결 관리에서 접근 권한을 철회할 수 있습니다. 로컬 데이터 및 앱 전용 저장 데이터는 사용자가 자신의 장치 및 Google 계정에서 관리할 수 있습니다.

6. 변경사항

기능과 데이터 처리 방식이 변경되면 이 방침을 실제 운영 방식에 맞추어 수정합니다.

Google API Services User Data Policy
